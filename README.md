### Tipos de problema que já entreguei

- Integrações entre ERP e SaaS de terceiros: sincronização de cadastros, eventos, atendimento e bilhetagem.
- Módulos de negócio voltados a RH, contratos, remuneração variável, gestão de recursos e processos de backoffice.
- APIs REST em Spring Boot 3 + Java 21 com arquitetura hexagonal, migrations com Flyway, autenticação JWT e observabilidade via Actuator.
- APIs Python com Flask/Bottle, SQLAlchemy, Pydantic, Gunicorn e I/O não-bloqueante via asyncio + uvloop.
- Ferramentas internas para devs: painel web em Node + Express + React + TypeScript que orquestra Docker, banco em container, servidor de aplicação nativo e bootstrap de WSL 2.
- Automações de negócio em n8n, Make, Coda.io e Google Apps Script para reduzir trabalho manual de áreas operacionais.

#### Painel de controle para ambiente local de devs

Ferramenta pessoal feita pra padronizar e acelerar o setup de ambiente em times que trabalham com **servidor de aplicação Java + Oracle**.

- **UI web** que detecta pré-requisitos em paralelo (Docker, JDK, portas, servidor) e direciona para os instaladores oficiais quando algo falta.
- **Orquestração**: sobe banco em container, inicia o servidor de aplicação nativo, expõe logs em tempo real via SSE.
- **Bootstrap de WSL 2**: instala Docker, Python (`uv`), Node (`nvm`), Git e VSCode com configurações sincronizadas com o Windows.
- **Hub de plugins de IA**: instala slash commands do Claude Code direto pela UI.
- **CLI** opcional que roda de qualquer lugar do terminal.
